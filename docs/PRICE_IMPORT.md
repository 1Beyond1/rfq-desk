# 规范价目导入

2026-10-24。本地CSV/XLSX结构化导入，必须人工审阅接纳；没有猜列、供应商实价或模型自动报价。页面提供明确标为合成的CSV/XLSX示例，业务文件请按同列结构制作，不覆盖原始材料。

列名及顺序必须精确为：

```text
part,unit,condition,currency,amount,valid_from,valid_until,lead_time,source,kind
```

| 列 | 规范 |
| --- | --- |
| part | 件号文本，前导零保留 |
| unit / condition | 按授权原件填写，与询价逐字匹配，不自动换算或释义 |
| currency | USD / CNY / EUR / GBP / JPY |
| amount | 有限正数字符串；金额按Decimal计算 |
| valid_from / valid_until | YYYY-MM-DD，生效日期不得晚于失效日期；价源过期可以归档，但不能用于当前批准 |
| lead_time | 原件给出的交期文本；没有依据不能编造 |
| source | 可读的来源编号、授权与位置说明 |
| kind | synthetic（合成）、manual（授权人工）、authorized（授权价表）；实际材料权利仍由提供者确认 |

CSV用UTF-8，可带BOM。XLSX仅一个工作表，首行为这些列名，所有单元格必须为文本，包括金额及日期；不接受数字单元格后猜测被Excel丢掉的前导零，也不执行公式。最多1000行、5MB，不支持任意格式映射。合成示例在`data/synthetic/product/prices-corrected.csv`和`.xlsx`；页面下载副本在`apps/web/templates/`。这些是程序生成的DEV格式样例，不是客户价目或美化的分析工作簿。

选择文件后先显示逐行预览、表/行位置及错误。缺值、非法数字/日期/币种、重复或冲突的件号+单位+件状都会阻止接纳；不部分污染当前价目。即便币种不同，匹配条件重复也不默选，因为现有询价没有指定选哪个币种。修改应在独立文件中明确裁定，保留旧原件。

预览默认追加；追加遇现有同物料条件冲突则拒绝。替换全部必须另选方式、勾选确认并填写核对人及理由。预览绑定当时工作版本，之后工作单或原价目文件变化则拒绝，重新上传审阅。归档在`var/price-imports/<case>/<import-id>/`，保存原字节/hash、工作表/行号、归一值hash、核对人和理由；正式批准及HTML/CSV/JSON输出重新核验归档原件和当前价格值。

原单条人工核价继续支持，表单来源说明必填。只有明确保存后生效，输入/价源变化使相关批准失效。原始文件不进入Git/待审参赛稿；`var/`、浏览器截图及下载继续本地忽略。
