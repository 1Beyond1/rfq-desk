# 本地演示与运行手册

本手册用于在不依赖外部 LLM 密钥的纯离线环境下，完整体验 **RFQ Desk** 的核心闭环：原件导入与行级溯源、候选审阅与局部修订、价格依据导入与核价、人工批准与变更失效拦截、本地版本快照 Diff 对比以及多格式报价输出。

---

## 1. 启动服务

在项目根目录执行：

```bash
# 本地 Python 直接启动（离线模式）
python distribution/serve.py

# 或使用 Docker Compose 一键启动
docker compose up --build
```

启动后访问 `http://127.0.0.1:5311/`（后端 API 监听 `http://127.0.0.1:8311`）。

> 如需体验多账号隔离与「访客体验」空间，可设置 `RFQ_AUTH_REQUIRED=1` 与 `RFQ_COOKIE_SECURE=0` 后启动，详见 [ACCOUNTS_AND_GUIDE.md](ACCOUNTS_AND_GUIDE.md)。

---

## 2. 快速主线演示（约 3 分钟）

1. **导入标准询价单**：在「我的工作单」页导入 `data/synthetic/tasks/lifecycle.eml`（或下载并填写页面提供的通用询价表模板 `rfq-template.csv`）。系统解析出两条同料号但不同询价号的记录，绝不自动合并。
2. **核对原文出处**：选中首行，点击字段旁的出处标记，在右侧原文对照窗格直接定位原文件行号与 SHA-256 摘要。
3. **补齐价格依据**：未录入有效价表前，批准与正式导出处于禁用状态。点击「价格依据」录入或导入符合 `docs/PRICE_IMPORT.md` 规范的有效价表（按 `part + unit + condition + 有效期` 精确匹配）。
4. **批准与多格式导出**：进入「批准当前版本」，核验四项检查全部通过后点击批准；切换到「报价输出」，可预览 HTML 报价单、下载 CSV 或双工作表格式化 Excel（`.xlsx`，前导零文本锁定并带公式注入防护），并一键复制中/英文客户报价回复邮件。
5. **变更失效与本地快照 Diff**：返回任意询价行修改数量或撤回价源，系统自动使旧批准失效并拦截旧版本导出（`409`）；进入左侧「版本与决策记录」，即可直观查看「上次批准 vs 当前版本」的字段级差异。

## 3. 进阶场景演练

### 重复、冲突与缺价处理
- 使用预置样例 `data/synthetic/demo.eml`（或在「其他预置样例」点击「重复、冲突与缺价」）：
  - 同料号不同询价号全部保留；完全重复记录可一键批量排除并记录理由；
  - 同询价号同料号数量冲突（2 vs 3）由人工裁定，不自动合计或覆盖；
  - 缺少「品相/件状」的通用采购表可通过队列顶部的「统一补充缺品相/件状行」批量补齐并留痕。

### 正文候选审阅与局部修订
- 使用 `data/synthetic/partial/base.txt` 建单并生成离线标签候选，人工核对后接纳为正式行并批准；
- 追加修订原件 `data/synthetic/partial/revision.txt` 并重新生成候选，选择「局部修订」仅更新目标字段（其余字段保留原有出处继承链），系统仅使受影响行及整单批准失效。

### 收件箱分流与参考库查询
- 在工作区首页点击「收件箱」并载入预置样例，可体验四分类分流（新询价 / 回信修订 / 非询价 / 可疑）、低置信或可疑邮件人工改判，以及将确认后的邮件建单或追加为原单修订；
- 在「库存与历史参考」或核价页内嵌三联参考面板中，可查询料号库存缺口、历史报价差异与显式替代关系（离线走本地 SQLite/关键词兜底；配置模型与 MatrixOne 后启用 `bge-m3` 向量检索与 `qwen3-rerank` 精排）。
