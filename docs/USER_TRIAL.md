## 任务二：处理输入修订并判断旧批准是否还能用（目标约7分钟）

打开“合成转发修订审阅”。请核对原文和候选，将数量2的原请求接纳为正式行；若时间紧可由记录员按本人指示设置USD10.00合成价源并批准（必须记一次协助及实际操作人）。随后给出新合成授权：“现在明确采用同一RFQ/件号的数量5修订，其他条件保持；请留下采用理由”。由参与者完成重新生成当前候选、显式替换、观察旧批准和导出状态。
